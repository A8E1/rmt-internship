# Automated verification

## What I built
Added .github/workflows/ci.yml with independent lint and test jobs on pushes and
pull requests. eslint.config.js checks the JavaScript tree; npm ci uses locked dependencies.

## The concept
Continuous integration runs repeatable checks. Required status checks are a separate
repository setting that can prevent merges; a green workflow alone cannot do that.

## The story
The replica gained 36 regression tests but no automatic execution. I added 2 jobs
using Node 22, npm caching, and read-only workflow permissions. I also checked branch
protection: GitHub returned HTTP 403 because this private repository needs Pro.
The owner chose to retain privacy and document the limitation. This work automates
verification; it does not claim merge enforcement.

## Follow-ups they'll ask
- Does CI gate merges? No. Required checks are unavailable on the current private-repo plan.
- Why two jobs? Lint and behavioral failures are visible independently.
- Why npm ci and caching? The lockfile fixes dependency versions; cached downloads
  save setup time without replacing the clean installation.
